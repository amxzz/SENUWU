Tahap 1: Pemuatan dan Pembersihan Data (Data Ingestion & Cleaning)

Pada tahap awal ini, program memuat berkas dataset sosial-ekonomi mentah berformat CSV. Program
melakukan inisialisasi variabel filter geografis (Pulau Jawa vs Luar Jawa) dengan menambahkan kolom
baru 'Is_Jawa'. Untuk meminimalkan skewness ekstrem pada variabel PDRB (Produk Domestik Regional
Bruto), dilakukan transformasi logaritma (np.log1p) menjadi 'PDRB_Log'. Selanjutnya, program
menghapus missing values pada fitur-fitur utama dan merangkum statistik deskriptif awal.

Tahap 3: Optimasi Jumlah Klaster (Elbow Method & Silhouette Score)

Penentuan K (jumlah klaster) optimal dievaluasi menggunakan metode Elbow (mengukur inersia /

WCSS) serta Silhouette Score untuk melihat kerapatan struktur klaster. Algoritma melakukan pencarian

otomatis pada rentang K=2 hingga K=10. Nilai K optimal didapatkan secara matematis melalui jarak

ortogonal terjauh dari garis regresi linier batas atas-bawah (siku) yang mendeteksi K=4 sebagai titik

potong terbaik.

          # TAHAP 3: Optimasi Jumlah Klaster (Elbow Method - WCSS)
          k_range = range(2, 11)
          wcss_values = []
          sil_scores = []
          for k in k_range:

                km = KMeans(n_clusters=k, init="k-means++", n_init=10, random_state=42)
                labels = km.fit_predict(scaled_features)
                wcss_values.append(km.inertia_)
                sil_scores.append(silhouette_score(scaled_features, labels))

Tahap 5: Analisis Spasial & Pembuktian Hipotesis Jawa-Sentris

Tahap ini merupakan inti dari pembuktian hipotesis ketimpangan pembangunan. Klaster diurutkan
berdasarkan rata-rata variabel kemiskinan secara descending dan dipetakan ke 4 Tipologi Polarisasi.
Analisis tabulasi silang (cross-tabulation) persentase dan jumlah absolut antara letak wilayah (Is_Jawa)
dengan Tipologi Polarisasi membuktikan bahwa 41.2% wilayah Pulau Jawa tergolong 'Maju di Semua
Indikator', sementara 0.0% wilayah Jawa masuk kategori 'Tertinggal'. Sebaliknya, kategori 'Tertinggal'
secara eksklusif diduduki oleh wilayah di Luar Jawa (8.1%).

          # TAHAP 5: Analisis Spasial Jawa-Sentris
          miskin_col = "Persentase Penduduk Miskin (P0) Menurut Kabupaten/Kota (Persen)"
          avg_miskin = df.groupby("Klaster")[miskin_col].mean().sort_values(ascending=False)
          labels = ["Tertinggal di Semua Indikator", "Berkembang (Kemiskinan Menengah-Tinggi)",

                          "Berkembang (Kemiskinan Menengah-Rendah)", "Maju di Semua Indikator"]

          peta_tipologi = {k: labels[i] for i, k in enumerate(avg_miskin.index)}
          df["Tipologi Polarisasi"] = df["Klaster"].map(peta_tipologi)

          crosstab = pd.crosstab(df["Tipologi Polarisasi"], df["Is_Jawa"], normalize="columns") * 100
          crosstab_abs = pd.crosstab(df["Tipologi Polarisasi"], df["Is_Jawa"])
